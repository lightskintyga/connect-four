# 4 в ряд (Connect Four)

Классическая логическая игра для двух игроков с поддержкой ИИ, настройками поля, тёмной темой и историей ходов.

[Демо](https://connect-four-alpha.vercel.app/)

---

## Особенности

- **Гибкое поле**: от 4×4 до 8×10 ячеек
- **Настраиваемая победа**: 3–6 фишек в ряд
- **Режимы**:
  - PvP
  - Против ИИ (легкий / сложный)
- **Подсветка выигрышной комбинации**
- **Undo / Redo** (в PvP)
- **Таймер партии**
- **Тёмная/светлая тема**
- **Реализовано определение тупиковых ситуаций, когда ни один из игроков не может победить**

Сложный ИИ реализован с помощью функции minimax с альфа-бета отсечением, а легкий ИИ построен на рандоме.
